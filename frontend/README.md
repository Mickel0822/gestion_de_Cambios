# Frontend de AnalytiCore

SPA React servida por Nginx con una interfaz neumórfica responsive. La organización interna separa dominio, aplicación, infraestructura y presentación.

La configuración de producción `VITE_API_URL` se inyecta durante el build Docker. Consulta el [README principal](../README.md) para ejecución, pruebas y despliegue.
